## 🎵 Overview

**Music Player** is a small web application built during my first steps with React and API integration.

The project was an opportunity to explore React fundamentals, experiment with fetching and displaying data from APIs, and understand how to build interactive web interfaces.

## 🎵 Project Goals

- Practice React components and state management.
- Explore API integration and data fetching.
- Build a simple and interactive music player interface.
- Gain hands-on experience with frontend development.
